HTML

HTML은 웹 문서의 구조를 만드는 표준 마크업 언어입니다. 텍스트, 이미지, 링크 등 다양한 요소를 정의하여 브라우저가 표시할 수 있게 해줍니다. 모든 웹 페이지의 기본 골격을 담당합니다.

CSS

CSS는 HTML로 작성된 웹 문서의 디자인과 레이아웃을 담당하는 스타일시트 언어입니다. 색상, 폰트, 배치 등 다양한 시각적 스타일을 지정하여 웹 페이지가 더 보기 좋게 꾸며집니다.

JavaScript

JavaScript는 웹 페이지에 동적인 기능을 추가하는 스크립트 언어입니다. 사용자와의 상호작용, 애니메이션, 실시간 데이터 처리 등 다양한 기능을 구현해 풍부한 웹 경험을 제공합니다.

PHP

PHP는 서버 측에서 동적으로 웹 페이지를 생성하는 데 쓰이는 프로그래밍 언어입니다. 데이터베이스 연동, 폼 처리 등 다양한 서버 업무에 활용되며, 많은 웹사이트에서 널리 사용됩니다.
