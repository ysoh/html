웹 기술 간략 소개

HTML, CSS, JavaScript, PHP에 대한 기본적인 개념을 소개합니다.

HTML (HyperText Markup Language)

HTML은 웹 페이지의 구조를 정의하는 마크업 언어로, 텍스트, 이미지, 링크, 표, 폼 등 다양한 요소를 배치하여 문서의 뼈대를 구성합니다. 웹 브라우저는 HTML 문서를 해석하여 사용자에게 콘텐츠를 시각적으로 표시합니다. 현재는 HTML5가 표준으로, 멀티미디어와 시맨틱 태그를 통해 풍부한 웹 표현을 지원합니다.

CSS (Cascading Style Sheets)

CSS는 웹 페이지의 디자인과 레이아웃을 담당하는 스타일시트 언어로, HTML 요소의 색상, 글꼴, 크기, 배치 등을 제어합니다. 선택자와 속성을 통해 웹 문서의 시각적 표현을 분리함으로써 유지보수성과 재사용성을 높입니다. CSS3는 애니메이션, 트랜지션, 반응형 디자인 등 다양한 시각 효과를 제공합니다.

JavaScript

JavaScript는 웹 페이지에 동적인 기능을 추가하기 위한 프로그래밍 언어로, 사용자의 입력 처리나 콘텐츠의 실시간 변경 등 상호작용을 가능하게 합니다. 모든 주요 브라우저에서 동작하며, HTML과 CSS와 함께 웹의 3대 핵심 기술로 꼽힙니다. 최근에는 Node.js를 통해 서버 개발에도 활용되고 있습니다.

PHP (Hypertext Preprocessor)

PHP는 서버 측에서 실행되는 스크립트 언어로, 동적인 웹 페이지를 생성하기 위해 널리 사용됩니다. 데이터베이스와 연동하여 사용자 맞춤형 콘텐츠를 제공할 수 있으며, WordPress와 같은 대표적인 CMS의 기반 언어이기도 합니다. 배우기 쉽고 다양한 웹 서버에서 지원되는 것이 장점입니다.
