웹 기술 간략 소개

HTML

HTML은 웹 페이지의 구조를 정의하는 마크업 언어입니다. 텍스트, 이미지, 링크 등 다양한 요소를 배치하며, 웹의 뼈대를 구성합니다. 모든 웹 페이지는 HTML을 기반으로 만들어집니다.

CSS

CSS는 웹 페이지의 디자인과 스타일을 담당합니다. 색상, 폰트, 레이아웃 등을 설정하여 HTML 요소를 시각적으로 꾸미고 사용자 경험을 향상시킵니다.

JavaScript

JavaScript는 웹 페이지에 동적인 기능을 추가하는 프로그래밍 언어입니다. 사용자와의 상호작용, 애니메이션, 폼 검증 등 다양한 기능을 구현할 수 있습니다.

PHP

PHP는 서버 측에서 실행되는 스크립트 언어로, 데이터베이스와의 연동, 사용자 인증, 동적 콘텐츠 생성 등에 사용됩니다. 많은 웹사이트와 CMS가 PHP로 구축되어 있습니다.
